    Special Information Boxes

    Key Terms Box

    KEY TERMS

    Notebook: A file format (.ipynb) that combines code, text, and output in a single document.

    Converter: The script that transforms .ipynb files into styled HTML pages.

    Cell: An individual unit of content inside a notebook — either markdown or code.

    Note Box

    NOTE

    All section headers (##) must live in their own markdown cell. Placing other content in the same cell as a header will break the HTML card structure.

    Tip Box

    TIP

    Use dashes instead of underscores in file names (e.g. my-lesson.ipynb) to avoid formatting accidents during conversion.

    Fact Box

    FACT

    Jupyter notebooks store their content as JSON, meaning every cell, its type, and its output are fully human-readable in a plain text editor.

    Warning Box

    WARNING

    SVG files are not copied during conversion. Use PNG, JPG, JPEG, or GIF for all images in lesson notebooks.

    Remember Box

    REMEMBER

    The introduction notebook's main # title is used as the module name across the platform. Make sure it is properly capitalised (e.g. Python Fundamentals 2).

    Important Box

    IMPORTANT

    Only include packages in the PACKAGES cell that are not built into Python. Installing unnecessary packages wastes load time and browser memory.

    History Box

    HISTORY

    The .ipynb format was created by the IPython project in 2011. It became the foundation of Project Jupyter, whose name honours the three programming languages originally supported: Julia, Python, and R.

    Markdown Tables

    The table below summarises all code cell marker types:

    Marker Runs? Shows Output? Collapsed?
    # DO NOT RUN No No No
    # RUN WITH OUTPUT Yes Yes No
    # RUN WITH NO OUTPUT Yes No No
    # RUN WITH OUTPUT COLLAPSABLE Yes Yes Yes
    # RUN WITH NO OUTPUT COLLAPSABLE Yes No Yes
    # SOLUTION No No Yes (toggle)
    # EDIT Yes Yes No
    # HIDDEN Yes No Hidden entirely

    Code in Markdown

    Use triple backticks in markdown cells for terminal commands or bash snippets that should be displayed but not run:

    git --version


    pip install numpy pandas matplotlib

    File Naming Reference

    The folder structure for any lesson should follow this convention:

    lesson_folder/
├── 00a_introduction.ipynb
├── 00b_glossary.md
├── 01_topic1.ipynb
├── 02_topic2.ipynb
├── images/
├── assets/
└── notebook_converter.py
