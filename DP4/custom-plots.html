    Introduction

    Throughout Data Processing the basics of plotting have been introduced, to help explore and understand the datasets at hand. Typically, each plot will tell you one or two things about the data: be it the shape, distribution, or averages. All of this information can be relevant to your downstream decisions, yet it can be clunky to create and view all of the plots separately. To this end, it can be useful to start blending plots together on the same axes, to better represent the data in one visualisation.

    In this section we will build upon and combine seaborn plots to make an enriched visualisation, one that can be called upon repeatably after being wrapped into a function.

    Standard Plot

    To visualise the results the barplot function can be used, giving a bar whose height equals the average (by default the mean).

    By default, seaborn, provides error bars that are a 95% confidence interval. In DP1 we demonstrated parametric confidence intervals where the lower and upper bounds are calculated from the standard error $SE = \frac{\sigma}{\sqrt{n}}$, scaled to the 95% percentiles:

    $$CI_{95} = \frac{1.96 \cdot \sigma}{\sqrt{n}}$$

    where:

    • σ = the standard deviation

    • n = the number of samples

    • 1.96 = 95% of the distribution

    This equation assumes the data is normally distributed, as explored in DP2, as the standard error around the average is thought to be symmetrical. Here, seaborn, instead uses a non-parametric version of confidence intervals, using bootstrap resampling to find the average $N$ times from a random subsample of the data. From this new distribution, the the lower and upper values are obtained by finding the values at the 2.5th and 97.5th percentile. This method is robust to any distribution, and will have - for example - non-symmetrical values in the case of a skewed set of data.

    The quantile range can be altered by giving to the argument errorbar a tuple ("ci", 99) where the first item indicates the type of estimation statistic and the second the quantile range of the upper and lower boundries. Below we have increased the confidence range to be 99% of the resampled means, and increased the number of iterations from 1000 (the default) to 3000.

    Combining plots

    A large drawback of a bar plot, and in a small way boxplots, is that the data points themselves are discarded despite the fact the numerical y-axis is present. Plotting the data points, per group, inherently gives the viewer an approximation of the dataset's distribution, which can then be used to internally validate the information from the statistical mean and error. For example, you may observe that there are extreme outliers or even a bimodal distribution that would invalidate the assumptions from differences in the mean. Boxplots do achieve this goal, however, by plotting the interquartile range you are visually preventing any other measurements of variance - such as confidence intervals - from being shown too.

    seaborn provides the strip plot function for generating categorical scatterplots, that is plots where one axis contains a single measurement and the other is split by categories, as seen below. This plot will show all the data points per category with added jitter to prevent overlapping; it is a great tool to enrich another plot as it provides the viewer with the raw data distribution, leaving no confusion around the truth behind the plot.

    Just from this plot alone you can see the difference between the two sexes.

    By default, strip plot has the hue categories on the same axis, which is useful for direct comparison. However, it precludes us from adding new plots on the same axis, as more information becomes layered, increasing the visual clutter.

    Changing the argument dodge to True from False sets the data that is altered by hue further apart from each other, giving each its own space for each category. With this in place, the plot is ready to have the confidence intervals per sub-group overlaid.

    Adding Confidence Intervals

    Both the bar and box plot consume a lot of the plotting space with both informative and redundant information. As the strip plot now provides the information about the distribution of the data, the last piece of information needed is the average and the confidence around it. Delving into the seaborn toolbox again, we can use point plot, which shows the averages for each group plus their error.

    Layering the plots

    seaborn plots can be layered onto the same plot by passing the same axis to the ax argument, similar to working with matplotlib.

    Doing so creates a plot close to what is wanted, as sadly the automated dodge function is different for each function, preventing them from properly overlapping. As the argument dodge also takes a floating point number that scales the amount of dodge from the centre, we can pass it this equation:

    $$0.8-\frac{0.8}{N_{hue}}$$

    where $N_{hue}$ is the number of unique categories in the hue column.

    This will ensure, no matter the number of categories in the hue column, that they dodge from the centre the same amount.

    NOTE

    The equation to have the same dodge for all functions was obtained by via other user feedback on Stack Overflow.

    Confirming the assumptions

    To round out this topic, we will quickly demonstrate how to statistically confirm that two groups are different using scipy stats.

    For the sample, we will find out if the Gentoo and Chinstrap Female penguins have statistically different bill length distributions.

    First, the data for each group must be isolated using conditional filtering, assigning the output to a new variable.

    These can then be passed to an independent T-test from scipy stats. Scipy stats provides nearly all the statistical tests you would need, including all the variations of the T-test.

    TIP

    Setting equal_var to False employs the Welch method, which does not assume the variance is equal. Given this is the most likely situation, you will almost always want this to be false. Scipy has it as True by default due to backwards compatibility, despite Welch being more common.

    Summary

    In this chapter, we explored how multiple visualisations can be combined and layered to communicate more information within a single figure. Using the Palmer Penguins dataset, we compared categorical groups and examined how bar plots, box plots, strip plots and point plots represent different aspects of a dataset, including averages, confidence intervals and the underlying distribution of observations. We explored Seaborn's bootstrapped confidence intervals, combined strip and point plots on shared axes and accounted for categorical hue and dodge when aligning plot layers. We then wrapped our custom visualisation into a reusable function before using SciPy to statistically assess differences between groups with an independent t-test.
