    Interactive Plots with Plotly DP4

    Learning Objectives

    1 Create interactive scatter plots from Pandas DataFrames using Plotly Express
    2 Explain the role of Plotly Figure objects and traces
    3 Add, remove and customise information displayed in hover labels
    4 Customise the layout and appearance of a Plotly figure using update_layout() and update_traces()
    5 Create update menus containing dropdowns and buttons
    6 Use interactive controls to show or hide traces and switch between variables within a figure
    7 Export interactive Plotly figures as self-contained or CDN-dependent HTML files

    Introduction

    Up to this point in the course, we have created plots using Matplotlib and Seaborn, which have largely been static in their presentation. Once a figure has been generated, the information displayed within it is fixed and can be readily exported for use in publications, reports and presentations etc. We have not, however, directly interacted with the data displayed within our figures, before.

    This section of Data Processing 4 introduces Plotly, a Python plotting library with powerful tools for easily creating interactive visualisations.

    Among many features, interactivity within a Plotly plot can allow you to:

    • Hover over individual data points to reveal additional information

    • Zoom into regions of interest

    • Pan around a plot

    • Show or hide particular groups of data

    • Select individual observations or regions

    • Create interactive controls for changing what is displayed
    When working with complex and layered datasets, this interactivity can provide useful ways to explore and navigate data. A static scatter plot might show us the overall relationship between two variables, for example, while an interactive version of it could allow us to inspect additional features associated with individual observations, simply by hovering over individual data points.

    This allows us to make additional information available when it is needed, without permanently adding that information to the visualisation and potentially making the figure difficult to interpret. As we will explore throughout this section, however, interactivity is most useful when it helps us investigate our data or answer a scientific question, rather than simply adding complexity to a figure. Economy and intentionality are key with good visualisations, and so we must be selective with how we use valuable plotting real estate to serve our observations and analyses.

    Plotly Express

    Plotly provides several ways to construct figures in Python. In this notebook, we will primarily use Plotly Express - Plotly's high-level interface for quickly creating common plots from DataFrames. Plotly Express creates standard Plotly figure objects behind the scenes, which can then be further customised using Plotly's lower-level Graph Objects interface if greater control is required.

    The conventional alias to use when importing plotly express is px.

    Loading the Clinical Dataset

    For our demonstration in this section of the lesson, we will be using the classic Heart Disease dataset - a widely recognised clinical dataset frequently featured on platforms like Kaggle and the UCI Machine Learning Repository. This real-world dataset contains anonymised patient records, including clinical features such as age, maximum heart rate achieved and serum cholesterol etc.

    It is a great candidate demonstrator for interactive plotting techniques, as it allows us to dynamically explore relationships between clinical measurements and observed heart-disease status, without overwhelming our display.

    Checking the shape of our DataFrame tells us that we have 14 columns, representing 14 recorded variables, or features, for each patient (or sample, represented by a row).

    KEY TERMS

    • In data science and machine learning, a sample (or observation) commonly refers to one individual item in a dataset. In a Pandas DataFrame, each sample is typically represented by a row.

    • A feature is a measurable property or variable associated with each sample. In a Pandas DataFrame, each feature is typically represented by a column.

    Drawing an interactive plot

    Let's create our first interactive scatter plot. We will plot maximum heart rate achieved (thalach) against age (age). Maximum heart rate achieved is measured when a patient is exercising, and is expected to decline with advancing age. This is partly due to age-related changes in cardiovascular function, and how the heart responds to strenuous exercise.

    We can also colour the points according to heart disease diagnosis (Diagnosis) to explore whether any immediate differences between the two diagnostic groups emerge.

    With Plotly Express, we can create a scatter plot using the px.scatter() function. Our exploration of Seaborn in the previous section will certainly give the syntax used some familiarity.

    We first pass our DataFrame, df, to the px.scatter() function, using the x and y arguments to specify which columns should be plotted on the x and y axes respectively:

    • x="age" places patient age on the x-axis

    • y="thalach" places maximum heart rate achieved on the y-axis

    • color="Diagnosis" colours each point according to the value in the Diagnosis column
    The px.scatter() function then creates a Plotly figure object, which we assign to the variable fig - rather like we did in earlier Data Processing lessons with Matplotlib. Calling fig.show() then displays the completed interactive figure, where each point represents one patient in the dataset, positioned according to their age and maximum heart rate achieved.

    As you explore the figure, consider whether the expected decline in maximum heart rate with advancing age is apparent within our data, and whether this relationship appears similar across the two diagnostic groups.

They allow you to navigate, make selections, pan around, zoom in or out of your plot, and - at a single click - reset the view. You can also save the figure as a static PNG file, which you can then open separately, if you wish.

Plotly will then automatically zoom to fill the figure space with the area outlined by your selection. To reset the view, you can simply double click within the figure space.

    Adding a trendline

    Visually inspecting a scatter plot can suggest that two variables might be related, but the appearance of a pattern alone does not really quantify that relationship.

    Within Plotly Express, we can fit a simple regression line directly to a scatter plot using the trendline argument. This provides an immediate way to investigate whether an apparent relationship within our visualisation is supported by a fitted statistical model.

    Setting trendline="ols" fits an ordinary least squares (OLS) regression line. For a simple linear regression, this takes the form:

    $$ y = mx + c $$

    where $m$ represents the slope of the fitted line and $c$ its intercept.

    KEY TERMS

    Ordinary least squares (OLS) chooses the line that minimises the sum of the squared vertical distances between the observed data points and the fitted line.

    When a categorical variable is also supplied using the color argument, Plotly fits a separate regression line to each group. In our example, this allows us to investigate the relationship between age and maximum heart rate separately within each diagnostic category.

    At first glance, both fitted regression lines suggest a negative relationship between age and maximum heart rate achieved. As age increases, maximum heart rate achieved during the exercise test tends to decrease, and this is clear from the downward trend observed in both healthy patients and heart disease sufferers.

    The relationship does, however, appear to differ slightly between the two diagnostic groups. The downward trend is particularly steep among patients without heart disease, while the fitted line for patients with heart disease is shallower. We can also see a difference in the overall position of the two groups, with patients diagnosed with heart disease tending to achieve lower maximum heart rates across much of the age range.

    These are interesting visual observations, but we should avoid judging the strength of a relationship from the appearance of a fitted line alone. Plotly stores the statistical models used to generate its trendlines, allowing us to examine these apparent relationships more quantitatively.

    We can retrieve these models using the px.get_trendline_results() function and extract several useful quantities:

    • The slope, which describes the direction and magnitude of the fitted linear relationship

    • $R^2$, which describes the proportion of variation in maximum heart rate accounted for by the fitted linear model

    • The p-value for the slope, which tests whether the fitted slope differs from zero under the assumptions of the regression model
    Together, these values will allow us to investigate whether the relationships suggested by our visualisation are supported by the fitted models.

    These values allow us to move beyond simply asking whether a relationship looks convincing in the scatter plot.

    For patients with no heart disease:

    • The slope of -1.056 suggests that maximum heart rate decreases by approximately 1 beat per minute for each additional year of age.

    • The $R^2$ value of 0.274 indicates that age accounts for around 27% of the variation captured by the fitted linear model, while the very small p-value provides strong evidence that the slope differs from zero.
    For patients with heart disease:
    • The relationship is much weaker. The slope shows a much more gradual descent at -0.368.

    • The $R^2$ is only 0.017, while a p-value of 0.129 provides insufficient evidence that the slope differs from zero.
    This is in line with the visual impression we get, where maximum heart rate shows a clear negative relationship with age in patients without heart disease, but there is, surprisingly, less evidence of a linear relationship within the heart disease group.

    IMPORTANT

    These regressions demonstrate association rather than causation, and do not test whether the relationship itself differs significantly between the two diagnostic groups.

    As for explaining why the relationship between these two variables differs in heart disease and healthy patients, one possibility could be that thalach reflects the maximum heart rate achieved during an exercise test, rather than a person's physiological maximum. Patients with heart disease may stop exercising because of symptoms such as angina, breathlessness or fatigue before reaching their maximum heart rate.

    Heart disease itself can also impair the heart's ability to increase its rate during exercise, and medications such as beta-blockers could further suppress this response. These additional influences could weaken the normal relationship between age and maximum heart rate.

    NOTE BOX

    Plotly Express uses the statsmodels package to fit OLS regression models. This package must therefore be installed in the Python environment for trendline="ols" to work.

    NOTE

    Adding variables to hover_data does not change the position or appearance of the points. It only changes the information displayed when we interact with them.

    Alternatively, we can supply a dictionary to hover_data when we want more control over the information displayed.

    While a list allows us to add columns to the hover label, a dictionary also allows us to explicitly include or exclude variables.     REMEMBER

    Supplying a dictionary to the hover_data argument can be useful because Plotly automatically displays variables already used to construct the plot (i.e. what was scattered on x and y axes).

    Unlike a list, using a dictionary here allows us to explicitly include or exclude these variables from the hover label, as well as control how their values are formatted. Often useful for avoiding wasting valuable hover label screen real estate!

    Customising the layout

    Interactivity is only one part of creating an effective Plotly figure. We will usually also want to improve the plot's layout, including its title, axis labels, legend and overall appearance.

    Recall that px.scatter() returns a Plotly Figure object which we have stored in fig. Once the figure has been created, we can modify it using methods belonging to this object.

    One of the most useful is fig.update_layout(), which allows us to change properties relating to the overall presentation of the figure.

    The underlying data have not changed. Instead, update_layout() modifies the instructions stored within the fig object that determine how the figure should be presented.

    Here, we have changed four layout properties:

    • title sets a descriptive title for the complete figure.

    • xaxis_title replaces the DataFrame column name age with a more informative x-axis label.

    • yaxis_title replaces thalach with a more informative y-axis label.

    • legend_title gives the colour legend a clearer title.
    Notice that we are first creating the figure with px.scatter(), then modifying the resulting Figure object with fig.update_layout(), and finally displaying it with fig.show(). As with any complex operation in Python, this cumulative and iterative way of working is very common when making figures with Plotly.

    Customising appearance

    We can also customise the appearance of the plotted data themselves. For scatter plots, each collection of points is represented internally by a Plotly trace. The update_traces() method allows us to modify properties of these traces after the figure has been created.

    Let's try making the markers slightly larger and partially transparent, for example.

    Increasing the marker size can make individual observations easier to inspect, while reducing their opacity helps reveal regions in which multiple points overlap. Both adjustments can improve the interpretability of the figure while also allowing us to customise its appearance.

    The distinction between these two methods is important to highlight:

    • update_layout() changes the figure as a whole, such as titles, axes and legends

    • update_traces() changes the data displayed within the figure, such as markers and lines
    Together, these methods allow us to start with the concise syntax of Plotly Express and then customise the Figure object in considerably more detail.

    KEY TERMS

    A trace is a single collection of data displayed within a Plotly figure. Each trace represents one visual layer or group of observations, such as a set of scatter points, a line or a group of bars.

    A single figure can contain multiple traces. For example, when we use color="Diagnosis" in px.scatter(), Plotly Express automatically creates a separate scatter trace for each diagnostic group. These traces can then be individually shown, hidden or customised.

    Within the context of a scatter plot, other appearance properties that you can modify include the colour, symbol and outline of your scatter plot's markers, as well as their size and opacity.

    Let's give each marker a dark outline and change its symbol from the default circle to a diamond. Notice that these changes affect the appearance of the observations without changing the data represented by the plot.

    update_traces() can also be used to change the way information appears when we interact with the data. For example, hoverlabel allows us to customise the appearance of the hover labels displayed when we move the cursor over individual observations.

    These options demonstrate the degree of control available through a Figure object. As with any visual encoding, however, additional styling should serve readability or interpretation rather than simply adding complexity.

    In this example, we changed the font family and size, as well as the colour of the hover label's border. Note how we use another, nested dictionary to specify both the family and size properties of the font argument.

    Advanced interactions

    So far, our interactions have allowed us to explore individual observations and navigate around a figure. Plotly can also add controls that change what the figure itself can display.

    This might be particularly useful in the sciences, where - rather than creating several separate figures to examine different subsets of patients, for example - we can allow the viewer to switch between these, interactively.

    Plotly provides these controls through update menus, which can be displayed as dropdown menus or sets of buttons.

    KEY TERMS

    Relative to Plotly, an update menu is an interactive control that allows the user to change properties of a figure, such as which traces are visible or which data are displayed.


    The controls are supplied to fig.update_layout() using the updatemenus argument. Each option is represented by a dictionary describing its label, what it should change and the values that should be applied.

    Let's sequentially break down some of the key components used to construct our update menu, in the Python cell, below.

    • updatemenus - an argument of update_layout() that accepts a list of dictionaries defining one or more update menus.

    • buttons - a dictionary key that accepts a list of dictionaries, each defining an option within the menu.

    • direction - a dictionary key that sets the direction in which the menu opens. "down" creates a dropdown menu.

    • showactive - a dictionary key that determines whether the currently selected option is highlighted.

    • x - a dictionary key that sets the horizontal position of the menu. 1.02 places it just beyond the right of the plotting area.

    • y - a dictionary key that sets the vertical position of the menu. 1 places it at the top of the plotting area.

    On the figure, try switching between the options.

    The underlying data have not been altered. Instead, the dropdown menu controls which traces are visible within the existing Figure object.

    The visible key accepts a list containing one Boolean value for each trace in the figure. For example, [True, False] displays the first trace and hides the second.

    This provides a convenient way of examining different diagnostic groups in isolation while retaining exactly the same axes and visual context for direct comparison.

    NOTE

    Plotly figures can contain multiple traces, each representing a separate collection of plotted data. When we use color="Diagnosis", Plotly Express creates a trace for each diagnostic category, depending on how many there are.

    Controls such as dropdown menus can therefore change the visibility or appearance of individual traces without recreating the entire figure.

    IMPORTANT

    Interactive controls are most useful when they help the viewer answer a meaningful question. Dropdowns and buttons can be used to reveal subsets of observations, compare measurements or change how data are displayed without requiring a separate figure for every view.

    NOTE

    Interactivity does not make a visualisation inherently more informative. Its value comes from allowing the viewer to reveal, compare or reorganise information in ways that help aid an investigation, without adding overwhelming complexity to the figure.

    When designing an interactive figure, always make a point of considering what the interaction adds and allows the viewer to discover that would be difficult to communicate as clearly in a simpler, static plot.
