Data Processing 4 - Glossary

Glossary DP4
Layered Visualisation: A visualisation in which multiple plot types or graphical elements are combined within the same axes to represent different aspects of a dataset, such as individual observations, distributions and summary statistics.
Confidence Interval (CI): A range of values calculated from sample data that describes the uncertainty associated with an estimated quantity, such as a sample mean.
Bootstrapping: A resampling technique in which repeated samples are drawn with replacement from an observed dataset to estimate the sampling distribution of a statistic.
Bootstrap Sample: A sample generated by randomly drawing observations with replacement from an existing dataset, typically containing the same number of observations as the original sample.
Percentile: A value below which a specified percentage of observations in a distribution fall. Percentiles can be used to determine the boundaries of a bootstrapped confidence interval.
Plotly: A plotting library for creating interactive data visualisations in Python and other programming languages.
Interactive Visualisation: A visualisation that allows a user to interact with the displayed data, for example by hovering over observations, zooming, panning or changing which information is displayed.
Figure Object: The Python object representing a complete Plotly figure, containing its data, traces and layout information.
Trace: A single collection of data displayed within a Plotly figure. A figure may contain one or multiple traces.
Hover Label: A small information box displayed when the cursor is positioned over an observation within an interactive Plotly figure.
Hover Data: Additional information associated with individual observations that can be displayed within Plotly hover labels.
Update Menu: An interactive Plotly control containing elements such as buttons or dropdown menus that can modify properties of a figure.
Ordinary Least Squares (OLS): A method for fitting a linear regression model by finding the line that minimises the sum of the squared differences between observed and fitted values.
Regression Line: A fitted line representing the estimated relationship between a response variable and an explanatory variable.
Slope: The estimated change in the response variable associated with a one-unit increase in the explanatory variable within a fitted linear relationship.
Residual: The difference between an observed value and the value predicted by a fitted statistical model.
R-squared ($R^2$): A measure describing the proportion of variation in the response variable accounted for by a fitted regression model.
3-D Scatter Plot: A scatter plot in which observations are positioned according to three numerical variables represented on x-, y- and z-axes.
Scene: The part of a Plotly 3-D figure layout that controls properties of its three-dimensional plotting space, including its axes, proportions and virtual camera.
Camera: The virtual viewpoint from which a Plotly 3-D scene is displayed. Changing the camera changes the viewing angle without changing the underlying data.
Aspect Mode: A Plotly setting controlling the relative physical scaling of the x-, y- and z-axes within a 3-D scene.
Dimensionality: The number of variables or dimensions used to represent observations within a dataset or visualisation.
Dimensionality Reduction: A family of techniques for representing data using fewer dimensions while attempting to retain important information or structure from the original data.
Information Loss: The loss or concealment of information that can occur when data are represented using fewer variables or dimensions.
HTML (HyperText Markup Language): A standard format for web content that can be used to save and share Plotly figures while retaining their interactive functionality.
